# xrayxl.com

The website for [XRayXL](https://github.com/XRayXL/XRayXL-AddIn) - a flight
recorder for the code running inside Excel.

One page. `index.html` is the whole site: hand-written HTML with inline CSS, no
build step, no JavaScript and no dependencies. Fonts come from Google Fonts;
nothing else is fetched. Open the file in a browser and you see exactly what is
served.

| File | What it is |
|---|---|
| `index.html` | The page |
| `assets/` | `ribbon.png` - the Developer tab. `options.png` - the Options dialog |
| `CNAME` | The custom domain GitHub Pages serves |
| `.nojekyll` | Serves the files as they are, without running Jekyll over them |

Published by GitHub Pages at [xrayxl.com](https://xrayxl.com/).
